Loki

An AI on-call engineer. When an alert fires, Loki reads the metrics, logs and recent deploys and forms a theory. Then it tries to reproduce the failure in a sandbox before it reports anything.

A second model checks every claim against the evidence. Only verified findings go into Loki's notebook, so it never learns from its own mistakes.

  • Found 14 of 15 incidents on a held-out test suite I built (a demo system, not production)
  • Takes alerts from Sentry, Datadog, PagerDuty and Grafana, and reports to Slack
  • Hands the fix to Claude Code over MCP

Promptly

An AI coding tool that runs the code it writes. When the code fails, Promptly reads the error, fixes the code and runs it again. You get code that has already worked once, not code that only looks right.

Tara

An AI that interviews job candidates by voice. It reads the job description and the candidate's resume, eases in like a person would, then asks about the work on the resume.

It doesn't take an answer at face value. If someone says "we" the whole way through, it asks what they did themselves. If they talk in theory when asked for an example, it asks for a real one. If an answer contradicts an earlier one, it brings that up. Everything it flags goes into the recruiter's report, with the evidence.

  • Talks in real time over LiveKit, with swappable speech and language models: Deepgram, Cartesia, OpenAI, Gemini, Sarvam
  • Screens resumes in a background queue (BullMQ on Redis) before anyone is invited
  • Next.js and Postgres run the hiring side: job posts, applications and reports
